# AlphaLattice research workstation
Date: 2026-10-03

AlphaLattice is a local equity research workstation. A person uses Local Web; a Codex or Claude Code session can use the maintained CLI. Product owners calculate and validate declared research, bind results to immutable inputs and publish records for review. This workflow does not execute trades or establish future returns. Start by giving your agent the repository link and one research intent; [Getting started](getting-started.md) is the setup owner.

Factor evidence supports curation and an Alpha study. Risk runs alongside those studies on the same input. Portfolio consumes Alpha scores and uses Risk only when the declared allocation reads it; Evidence and the CRO review the resulting book. A report-only Risk association does not mean the weights used Risk.

## Read results within their scope

A study records its input, method, evaluated sessions, information cutoff and execution bounds. Read those with its coverage and temporal statement. Membership and Sector backfill, survivorship and price basis limit what the evidence can claim. A successful command or publication is not a scientific endorsement.
