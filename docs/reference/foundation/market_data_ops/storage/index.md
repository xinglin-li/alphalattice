# alphalattice.foundation.market_data_ops.storage
Date: 2026-09-26

Market data physical storage owner.

World's markets have Host-minted `market_id` values. MICs are dated names on
versioned market records; listings and sessions link to the market's stable id.
A MIC change preserves session identity and the knowledge cutoff of each read.

The registered market upgrade family uses the shared first-start runner for
older workspaces, admitting and comparing their tables in a new root before the
reader switch. Earlier development roots remain refused by name.

Sessions generated by the pinned `exchange_calendars` rules are reference data
known before every cutoff; each version retains its rule origin and package
version. A recorded source observation takes precedence. Later corrections keep
their later knowledge time, so they cannot move an earlier membership read.
