# Security Policy
Date: 2026-10-08

Report suspected vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's Security tab and choose
[Report a vulnerability](https://github.com/xinglin-li/alphalattice/security/advisories/new).
Do not open a public issue or pull request containing vulnerability details.

Include the affected version or commit, a description of the impact and a
minimal reproduction using synthetic or redacted data. Do not send credentials,
provider payloads, conversation text, private research or personal data.

The maintainer will coordinate investigation, a fix and public disclosure with
the reporter. Keep vulnerability details private until that disclosure is agreed.
