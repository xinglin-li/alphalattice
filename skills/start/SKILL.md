for the person's terminal in the chosen folder. If detached or background start
is unavailable, use the person's terminal as the product's guide describes.

in the [agent guide](../../AGENTS.md) from the same folder. Use the installed
`alphalattice:alphalattice-research` skill for research.
The product CLI remains the entry for all requests. Retain the guide's pinned
uvx prefix, workspace and data-root setting for follow-up commands. Give them to specialists.
Claude Code identifies the plugin's specialist roles with the `alphalattice:` prefix.
